## FreeBuild 自由搭

**企业级零代码应用搭建平台**

FreeBuild（自由搭）是一款开源企业级零代码 / 低代码平台。业务人员无需编码，通过可视化拖拽与表单配置，快速搭建表单、审批流程、数据仪表盘、数据管理应用，用来构建 OA、工单、CRM、进销存、台账等企业内部小系统，可私有化部署，作为简道云开源替代方案。

### ✨ 核心能力

- 📝 **可视化表单设计器**：丰富字段类型，支持关联数据、子表单、校验规则、默认值、隐藏联动，快速搭建业务单据
- 🔄 **流程引擎**：可视化审批流，分支条件、会签 / 或签、节点权限、抄送、回退，满足企业各类审批场景
- 📊 **数据仪表盘**：数据视图、表格、图表、筛选，汇总业务数据，自定义数据看板
- 🧩 **数据管理**：应用隔离、数据权限、行权限、列权限，精细化控制企业数据访问
- 📦 **应用打包**：一套平台，创建多个独立业务应用，按需分配给内部不同部门
- 🚀 **私有化部署**：完整自托管，数据留存企业内网，Docker 一键启动
- 🔌 **开放集成**：Webhook、API 接口，支持和内部系统打通，外部数据读写
- 🧱 **插件扩展**：支持自定义组件、脚本扩展，开发者可扩展平台能力

### 🎯 适用场景

- 企业内部 OA、请假、报销、采购审批
- 工单管理、售后报修、项目台账
- 简易 CRM、客户跟进、线索管理
- 库存、资产、设备台账、进销存小系统
- 各类业务收集表单、数据统计报表

> 面向人群：业务人员、IT 运维、开发者。业务人员搭建应用；IT 负责部署与权限管控；开发者基于源码二次开发。
